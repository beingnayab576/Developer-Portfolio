# Developer Portfolio

A responsive personal developer portfolio website built using HTML5, CSS3, and Vanilla JavaScript. This website showcases my introduction, skills, projects, and contact information.

## About the Project

This portfolio website is created as part of the CS554 Advanced Web Technologies Assignment 1. It provides information about me as a developer and displays my projects in a clean and responsive layout.

## Pages

- **Home (`index.html`):** Introduction, about section, and technical skills.
- **Projects (`projects.html`):** Displays project cards with search and technology filtering.
- **Contact (`contact.html`):** Contact form with input validation.

## Features

- Responsive design for mobile, tablet, and desktop.
- Dark mode and light mode.
- Theme preference saved using Local Storage.
- Dynamic project cards generated using JavaScript.
- Search projects by title and technology.
- Filter projects by technology.
- Contact form with JavaScript validation.
- Accessible and user-friendly interface.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
- CSS Grid and Flexbox
